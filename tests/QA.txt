Findings – Issues Not Matching Expected Behavior

1. Header Consistency
Please make the header consistent across all pages. Currently, the headers in Payments, Residents, Blocks, User Management, and Reports differ from the Dashboard (Title, Subtitle, and Light Mode layout).
Search and notification icons do not need to appear on every page.
Buttons such as Add Block, Add New Resident, Print Report, Create User, and Auto Approval should follow a consistent header structure.

2. Body Content Layout Inconsistency
In the User Management page, the content is wrapped inside a div with the class:
flex-1 p-6 lg:p-8 space-y-6
However, other pages do not use this structure, resulting in inconsistent layouts. This is especially noticeable on the Residents page where the left and right spacing look uneven.

3. Currency Inconsistency
The currency format is not consistent. The Dashboard uses "$", while the Payments page uses "Rp".
The correct currency should be "Rp". Please update all currency displays to use Rp.

4. Quick Actions Not Working
The Quick Actions section on the Dashboard is currently not functional.
Please confirm whether this feature is still required:
- If yes → make it functional.
- If not → remove it.

5. Dropdown UI Issue in Payments Page
In the Payments page, the dropdown arrows for Block and Status overlap with the text. Please fix the UI alignment.

6. Payments Filter Behavior
Please add a Search button to the filter section.
Currently, filtering happens automatically whenever changes are made.
Filtering should run only after clicking Search, as automatic filtering feels disruptive and may impact CPU performance.

7. Residents Page Action Buttons Usability
Action buttons only appear on hover, which is not user-friendly.
Please make them always visible.
Additionally, when a resident status is Inactive, the Deactivate button should be disabled.

8. Blocks Page Action Buttons
Similar to the Residents page, action buttons appear only on hover.
Please make them always visible.

9. Deactivate Button in Blocks Page
The Deactivate button in the Blocks page seems inefficient.
Consider replacing it with a Delete button, since users may enter incorrect Block data and want to recreate it.
When clicking Delete, show a confirmation modal similar to the Residents page (Deactivate action).
Currently, Blocks uses the browser default confirmation, which is inconsistent with other pages.

10. Remove “More Filter” in User Management
The More Filter option in the User Management page is unnecessary.
Please remove it and replace it with a Search button.

11. User Management Filters Not Working
The filters in the User Management page currently do not work.
Please implement the filtering functionality.

12. Block Assignment Data Not Synchronized
The Block Assignment field in the Approve, Add, and Edit User modals is not based on the Blocks data.
Please synchronize it so the data source matches the Blocks table.

13. Reports Page Button Naming
Please rename the Apply button in the Reports page to Search.
